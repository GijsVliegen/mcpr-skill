# MCPR Skill

An Agent Skill that helps AI agents work with **[MCPR](https://github.com/phisanti/MCPR)**.

## Requirements

* Node.js and `npx` for installation via the Skills CLI.
* The MCPR server configured in your AI agent.
* An AI agent that supports Agent Skills.

## Installation

Install this skill using the [Skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add GijsVliegen/mcpr-skill --skill mcpr-skill
```

Follow the CLI prompts to select your target agent, if applicable.

**Important:** This installs the skill instructions. You must configure the MCP server separately.

## Usage

Once installed and the MCP server is configured, ask your agent to retrieve an object from your R console

## Manual installation

You can also download [`SKILL.md`](mcpr-skill/SKILL.md) directly and place it in the appropriate skill directory for your agent.
